# Specs

The archive of specs: how what a user sees and does should behave (interaction, navigation,
layout at 1920 / 1440 / 390 px, what a screen reader hears). A file is `<YYYY-MM-DD>-<slug>.md`,
with the slug of the branch `my-<n>-<slug>`. A spec is written when a task changes observable
behavior and committed with the plan, in one commit, before any code (`ai/workflow.md`, step 5).
Read only the spec of the feature you change.
