# Plan: page-hero (MY-191)

Goal: one hero partial for Careers, About and Security, taken from `careers-hero`. No spec: the
Careers page looks and behaves as before, apart from the refinements listed below. No open questions.

## Changes

- `partials/sections/careers/careers-hero.html` → `partials/sections/shared/page-hero.html`, block
  `.page-hero` (`__inner`, `__content`, `__eyebrow`, `__title`, `__text`, `__image`).
- The partial takes one context, an entry's `hero` from `data/pages.js`:
  `eyebrow` (optional), `titleStart` / `titleAccent` / `titleEnd` (as `section-heading`), `text`,
  `image: { src, alt, width, height }`. A page calls it as `{{> sections/shared/page-hero page.hero }}`,
  so About and Security (MY-199, MY-201) add a `hero` entry and one line.
- The content of Careers moves to `pages.careers.hero`; no new data file and no new `context` key.
- The photo is WebP with `fetchpriority="high"` (it is the LCP) and no `loading`, with `width` and
  `height`. `alt=""` keeps `aria-hidden="true"`, otherwise `aria-hidden="false"`, in the value (the
  `aria-current` pattern, `ai/rules/html.md`).
- `styles/sections/careers-hero.css` → `page-hero.css`, import updated. The text card was absolutely
  positioned over the photo, so a long text overflowed the panel; from 1024 px the card and the photo
  now share one grid cell (card at the start, photo at the end), so the panel grows with the taller of
  the two. Below 1024 px the column is unchanged.
- The eyebrow (About's "Welcome to YourBank") is `--text-page-hero-label`, a new fluid token
  (20 / 18 / 14, `ai/design-system.md`), white, weight 400, line 1.5.
- The text is a `<p>` (it was a `<div>`).

## Docs

- `ai/map.md`: the pages line, the partials line.
- `ai/design-system.md`: the label token, the page-hero grid.
- `ai/skills/section.md`: nothing — the pattern it describes did not change.
